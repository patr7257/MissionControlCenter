# Office (Humaaans) view - status and next steps

Date paused: 2026-06-30

## State
The dashboard has two views (header toggle `Pro | Office`). The Office view was rebuilt to
use CC0 Humaaans characters in a flat 2.5D room (was a plain isometric stick-figure scene).

- Characters: `public/humaaans.js` holds 12 recolorable inline-SVG poses (6 sitting, 6
  standing), generated by `scratchpad/build-humaaans.mjs` from the `react-humaaans` (jzarca01)
  JSX sources. Per agent, colors + pose are picked deterministically from the agent id.
- Renderer: `public/view-office.js` places one character per agent at a workstation desk
  (sitting while working), walks them in from the door, shows a per-tool activity bubble,
  celebrates and moves them to the lounge when done. Reuses the shared Store + view interface.
- Room styles: the office block in `public/style.css` (flat room, window, door, deskfronts
  with monitors, sofas, lounge).
- All offline / zero-dependency; verified: all 12 poses render clean at runtime, recolor works.

## This is a FIRST visual pass - tuning still needed
Likely adjustments once viewed in the browser:
- Character size vs desk; desk-front overlap on the legs (`DESK_DX`/`DESK_DY` in view-office.js).
- Workstation spacing / room proportions (`ORIGIN`, `GAP`, room width/height; `rescale()`).
- Walk path from the door; lounge seat layout.
- Possibly add props (plants, coffee) and tune wall/floor colors.
